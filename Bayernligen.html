noch aktuelle Ergebnisse eingetragen werden. Den Zeitpunkt der Erstellung erkennt man in der Überschriftszeile.

Ganz aktuelle Daten findet man über den Link auf die basketball‑bund.net‑Seite.
Wenn eine andere Liga interessiert, kann man die 5‑stellige Zahl (= LigaNr) durch die LigaNr der gewünschten Liga ersetzen.
Wenn für diese Liga bereits etwas generiert wurde, ist die entsprechende Seite vorhanden.

Die LigaNr findet ihr auf der basketball‑bund.net‑Seite.
Wenn man die Liga gefunden hat (in der Übersicht wird nur „Liga“ angezeigt) und diese Liga aufruft, sieht man im aufgebauten Link die LigaNr.

Wenn Interesse besteht, kann man sich für Vereine eine eigene Liste zusammenstellen lassen.
Hierzu benötigt man folgendes:

Man erstellt eine Liste mit LigaNummern in dieser Form: 

LIGA_IDS_NN = [
    54453, 54485, 54459, 54488, 54491, 54471,
    55701, 54498, 55699, 54482
]

Zusätzlich muss der Aufruf entsprechend angepasst werden: 

REM             Schalter Dateiname                       Im HTML                
"%PYTHON%" "%SCRIPT%" NN BBV_SCH_VSC_BASKETS_Donauwoerth "VSC Baskets Donauwoerth"

Damit kann man eine eigene Liste erzeugen.
Zum Testen ist dies vorerst auf Vereine im Bezirk Schwaben (BBV_SCH_...) begrenzt.
Wenn dies funktioniert, kann man dies später erweitern.
